# Switcher

Утилита для macOS, которая автоматически исправляет текст, набранный не в той раскладке клавиатуры — без горячих клавиш и ручного переключения.

```
ghbdtn  →  привет   (набрано в EN, нужно было RU)
ye,kf   →  яблоко
lbdfy   →  диван
```

---

## Возможности

- **Автопереключение** — распознаёт слово, набранное не в той раскладке, и заменяет его сразу после пробела, знака препинания или Enter
- **Двойной Shift с выделением** — конвертирует выделенный текст между EN и RU
- **Двойной Shift без выделения** — отменяет последнюю автоматическую замену
- **Правила исправления опечаток** — например, `чтото → что-то`, работают независимо от раскладки
- **Обучение** — при отмене слово добавляется в исключения; при двойном Shift — конвертированные слова сохраняются как правила для следующих автоматических замен
- **Исключения по приложениям** — автопереключение можно отключить для конкретных программ (редакторы кода, терминалы)
- **Словарь исключений** — слова, которые никогда не нужно переключать; поддерживает импорт/экспорт JSON и plain text

## Сборка

### Требования

- macOS 14 Sonoma или новее
- Xcode Command Line Tools:
  ```bash
  xcode-select --install
  ```

### Команды Make

```bash
# Собрать release-бандл, подписать ad-hoc и запустить
make run

# Только собрать .app (без запуска)
make bundle

# Только компиляция в debug-режиме
swift build

# Удалить артефакты сборки и .app
make clean
```

После `make bundle` в корне проекта появляется `Switcher.app`. Приложение подписывается ad-hoc подписью (`codesign --sign -`) — для локального использования Apple Developer аккаунт не нужен.

### Разрешения

При первом запуске macOS потребует разрешение **Специальные возможности**:

1. Системные настройки → Конфиденциальность и безопасность → Специальные возможности
2. Добавить `Switcher.app` в список

Без этого разрешения event tap не создаётся и приложение ничего не делает.

### Иконка

`Resources/AppIcon.icns` уже включена в репозиторий. Для перегенерации:

```bash
swift Resources/generate-icon.swift
```

Скрипт использует AppKit и `iconutil` — создаёт все размеры (16–1024 px) из одного нарисованного шаблона.

## Как это работает

### Event tap

Приложение регистрирует системный `CGEventTap` на уровне сессии (`.cgSessionEventTap`, режим `.headInsertEventTap`) с перехватом событий `keyDown` и `flagsChanged`. Tap установлен в голове очереди — это позволяет читать нажатия до того, как их получит активное приложение, и при необходимости блокировать события (возвращая `nil` из колбэка).

Колбэк — C-совместимая свободная функция `eventTapCallback`, которая через `Unmanaged` вызывает метод экземпляра `KeyboardEngine`.

### Алгоритм автопереключения

```
клавиша нажата
    │
    ├─ буква → добавить в wordBuffer
    │
    ├─ backspace → убрать последний символ из wordBuffer
    │
    ├─ пробел / знак препинания / Enter  ←── ТРИГГЕР
    │       │
    │       ├─ wordBuffer.count < minWordLength → пропустить
    │       ├─ приложение в списке исключений  → пропустить
    │       ├─ поле — пароль (AXSecureTextField) → пропустить
    │       ├─ слово похоже на URL / email / путь → пропустить
    │       │
    │       ├─ есть правило исправления для слова → применить (без переключения раскладки)
    │       │
    │       └─ SpellCheckService.detectWrongLayout()
    │               │
    │               ├─ слово корректно в текущей раскладке → не переключать
    │               ├─ конвертировать через LayoutConverter
    │               ├─ конвертированное слово некорректно → не переключать
    │               └─ OK → TextReplacer.replaceLastTyped() + InputSourceManager.switch()
    │
    ├─ Escape / стрелки / Tab → сброс wordBuffer
    │
    └─ модификаторы (Cmd/Ctrl/Alt) → сброс wordBuffer и lastSwitch
```

### Валидация через орфографию и n-граммы

`SpellCheckService` использует два метода:

**NSSpellChecker (основной)** — системный спелл-чекер macOS. Слово должно быть некорректным в текущей раскладке и корректным после конвертации.

**N-gram анализ (запасной)** — если словарь целевого языка не установлен. Проверяет наличие биграмм из топ-40 самых частых для EN и RU. Например, `xnjnj` не содержит ни одной английской биграммы → не English; `ghbdtn` содержит `br` (слабо) → дополнительно проверяется `привет`, который содержит `пр`, `ри` → Russian.

Чисто скриптовая проверка (Unicode-блоки) намеренно не используется: она давала бы ложные срабатывания на слова вроде `xnjnj` — это всё латиница, но не английский.

### Конвертация раскладки

`LayoutConverter` хранит статическую таблицу из 70 пар (строчные + прописные). Каждый символ QWERTY соответствует символу на той же физической клавише в ЙЦУКЕН:

```
физ. клавиша   QWERTY   ЙЦУКЕН
Q              q / Q    й / Й
W              w / W    ц / Ц
E              e / E    у / У
...
```

Таблица RU→EN строится инверсией EN→RU автоматически.

Два режима работы:
- `strict: true` — любой немапируемый символ → пустая строка. Используется при автопереключении
- `strict: false` — немапируемые символы передаются как есть. Используется при двойном Shift на произвольном выделении

### Замена текста

`TextReplacer` предоставляет два пути:

**AX API (быстрый путь)** — `kAXSelectedTextRangeAttribute` для выделения нужного диапазона, `kAXSelectedTextAttribute` для замены. Мгновенно, не трогает буфер обмена. Используется для отмены и замены выделенного текста при двойном Shift.

**Backspace + Paste (фолбэк)** — синтетические события backspace для стирания слова + Cmd+V для вставки через `NSPasteboard`. После вставки оригинальное содержимое буфера обмена восстанавливается. Используется при автопереключении и в приложениях без поддержки AX.

Пока замена в процессе, флаг `isReplacing = true` пропускает все входящие события без обработки — иначе синтетические backspace'ы и Cmd+V зациклились бы через tap.

### Двойной Shift

`handleFlagsChanged` отслеживает события с `keyCode` 56 (левый Shift) или 60 (правый Shift). Если между двумя последовательными нажатиями прошло менее 0.4 с — двойной Shift.

Логика:
1. Через AX API проверяем `kAXSelectedTextAttribute`
2. **Есть выделение** → определяем язык по доле символов кириллицы/латиницы, конвертируем через `LayoutConverter` в режиме `strict: false`, вставляем через AX
3. **Нет выделения** → если есть активная запись `lastSwitch` (не старше 5 секунд) → отмена через AX API

### Словарь и обучение

`SwitchDictionary` хранится в `~/Library/Application Support/Switcher/dictionary.json` (pretty-printed JSON, стабильный diff).

Содержимое:
- `exceptions` — слова, которые никогда не переключаются (массив, отсортированный для стабильного diff)
- `excludedApps` — bundle ID приложений-исключений
- `corrections` — правила замены опечаток: `[{from: "чтото", to: "что-то"}, ...]`

При включённом обучении:
- **Отмена двойным Shift** → исходное слово добавляется в `exceptions`
- **Двойной Shift с выделением** → каждая пара `оригинал/конвертированный` добавляется в `corrections`; в следующий раз это слово заменится автоматически без двойного Shift

## Настройки

Все настройки хранятся в `UserDefaults`. Словарь — отдельный JSON-файл (см. выше).

| Настройка | По умолчанию | Описание |
|---|---|---|
| Включить Switcher | вкл | Глобальный on/off, включает/останавливает event tap |
| Автопереключение | вкл | Переключение раскладки при вводе слова |
| Двойной Shift | вкл | Конвертация выделения / отмена последней замены |
| Проверять орфографию | вкл | NSSpellChecker перед n-gram анализом |
| Минимальная длина слова | 4 | Слова короче не проверяются |
| Обучение | вкл | Накопление исключений и правил замены |
| Запускать при входе | выкл | Регистрация через `SMAppService.mainApp` |
